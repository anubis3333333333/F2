# Flutter 2

Консольное приложение для управления списком задач (создание, просмотр, отметка о выполнении и удаление). Проект разработан в рамках изучения основ объектно-ориентированного программирования (ООП) на языке Dart.

## Запуск
1. Клонировать репозиторий:
   ```bash
   git clone <url>
   ```
2. Перейти в папку проекта:
   ```bash
   cd f2
   ```
3. Установить зависимости:
   ```bash
   dart pub get
   ```
4. Запустить приложение:
   ```bash
   dart run
   ```

## Что изучили
1. **Основы ООП в Dart:** научились создавать классы, объявлять поля с учетом null-safety, использовать краткую запись конструкторов и именованные параметры.
2. **Геттеры и статические поля:** реализовали вычисляемое свойство (`status`) и статический счётчик (`_counter`) для автоматической генерации уникальных ID.
3. **Управление потоком и CLI:** построили бесконечный цикл `while (true)` с использованием оператора `switch-case` для обработки команд пользователя из терминала через `stdin.readLineSync()`.
4. **Работа с внешними пакетами:** подключили и настроили пакет `ansicolor` через `pub.dev` для цветового оформления консольного вывода.

## Ответы на вопросы

### 1. В чём разница между полем класса и обычной переменной в функции?
* **Поле класса** принадлежит объекту (или всему классу) и сохраняет своё значение на протяжении всей жизни этого объекта. 
* **Обычная переменная в функции** является локальной: она создаётся в момент вызова функции и полностью уничтожается (стирается из памяти) сразу после завершения работы этой функции.

### 2. Что такое конструктор и зачем он нужен?
Конструктор — это специальный метод класса, который автоматически вызывается при создании нового экземпляра (объекта). Он необходим для инициализации начального состояния объекта (заполнения его полей переданными значениями).

### 3. Зачем нужен `@override` перед `toString()`? Что будет, если его убрать?
Аннотация `@override` указывает компилятору, что мы переопределяем метод `toString()`, который изначально принадлежит базовому классу `Object`. Она защищает от опечаток: если вы случайно ошибётесь в имени метода, компилятор сразу выдаст ошибку. Если убрать `@override`, код всё равно скомпилируется и будет работать, но исчезнет автоматическая проверка безопасности со стороны компилятора.

### 4. Чем статическое поле `static int _counter` отличается от обычного поля? Сколько копий этого поля существует в программе?
* **Обычные поля** дублируются для каждого объекта индивидуально (у каждого объекта свой `id` и `title`). 
* **Статическое поле** принадлежит самому классу целиком, а не его экземплярам. В программе существует **всего одна копия** статического поля, общая для всех создаваемых объектов.

### 5. Что означает нижнее подчёркивание в `_counter`?
В языке Dart нижнее подчёркивание в начале имени означает, что данный идентификатор (переменная, поле или метод) является **приватным**. Доступ к нему ограничен рамками того файла, в котором он объявлен.
